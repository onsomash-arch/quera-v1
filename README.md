# Quera

**Quera** — desktop music application focused on providing a modern, convenient and consistent music listening experience.

The project combines a minimalistic user interface with a Python-based application architecture and web technologies.

---

## Overview

Quera is designed to provide users with a streamlined environment for music playback and media management.

The application focuses on usability, performance and a consistent visual identity.

## Features

- Modern desktop interface
- Dark visual theme
- Music playback functionality
- Audio metadata processing
- Integrated application interface
- Windows support
-Full Custom

*Features and functionality are subject to change during development.*
